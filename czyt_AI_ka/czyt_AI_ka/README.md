# czyt_AI_ka

## Poborca i Rabusie – assety

Aby podmienić grafiki w grze „Poborca i Rabusie”, skopiuj pliki PNG (1024x1024) do katalogu:

```
wwwroot/games/tribute/
```

Wymagane nazwy plików:

- `gniezno.png`
- `giecz.png`
- `ostrow_lednicki.png` (używane przez Ostrów i Lednicki)
- `kruszwica.png`
- `poznan.png`
- `krakow.png`
- `grzybow.png`
- `karczma.png`
- `tax_collector.png`
- `bandit.png`

Opcjonalnie możesz dodać tło mapy pod nazwą `background.png` (również 1024x1024). Jeśli brakuje któregoś pliku, gra wyświetli kolorowy placeholder.
